Guide for running the Project

1. First make sure you have the backend libraries installed to run the backend, do this by making sure you're installed
the backend folder ("cd backend"), then run "pip install -r requirements.txt"
2. To run the backend simply make sure you are in backend folder and run "flask run"
3. To launch frontend, use a separate terminal while backend is running, go to frontend folder in this one ("cd frontend")
4. To run the frontend, simply make sure you are in the frontend folder and run "npm start"
5. Now yuo can go to http://localhost:3000/ to access the site
